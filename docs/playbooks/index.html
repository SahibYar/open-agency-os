n8n recipes

Nine automation playbooks that cover the core GHL stack

JSON exports live in n8n/workflows/ on GitHub. Import them after the core profile is up. Activate one at a time after a successful manual test.

  1. 01 · Form to CRM

    Form → validate → Twenty + Chatwoot + Mautic

    Trigger: POST /webhook/aperture-lead

    1. Validate & normalise email + E.164 phone.
    2. Create person in Twenty.
    3. Create contact in Chatwoot.
    4. Create contact in Mautic.

  2. 02 · Speed to lead

    Webhook → Twilio SMS

    Trigger: POST /webhook/aperture-sms

    1. Receives to + body.
    2. Sends SMS via Twilio API.

  3. 03 · Booking to pipeline

    Webhook → Cal.com + Twenty opportunity

    Trigger: POST /webhook/aperture-booking

    1. Create Cal.com booking.
    2. Create Twenty opportunity at Appointment stage.

  4. 04 · Inbox note

    Webhook → Chatwoot private note

    Trigger: POST /webhook/aperture-reply

    1. Posts a private note on a Chatwoot conversation.

  5. 05 · Missed call text back ⭐

    Missed call → immediate SMS reply

    Trigger: Twilio voice status webhook

    1. Twilio sends call status event.
    2. Filter: inbound no-answer / busy only.
    3. SMS: "Sorry I missed your call, book here: …"
    4. Create Chatwoot contact for the caller.

  6. 06 · Lead follow-up sequence ⭐

    Form → SMS now → SMS in 10 min → Mautic nurture

    Trigger: POST /webhook/aperture-lead-followup

    1. Validate & normalise.
    2. Send immediate SMS.
    3. Create in Twenty + Mautic, enrol in nurture segment.
    4. Wait 10 minutes.
    5. Send follow-up SMS.

  7. 07 · Appointment reminder ⭐

    Schedule → Cal.com API → reminder SMS 24h before

    Trigger: Schedule (every hour)

    1. Fetch upcoming Cal.com bookings.
    2. Filter to bookings starting in 23–25 hours.
    3. Send reminder SMS to each attendee with a phone number.

  8. 08 · Review request ⭐

    Appointment done → wait 2h → Google review SMS

    Trigger: POST /webhook/aperture-booking-done

    1. Extract attendee from webhook.
    2. Wait 2 hours.
    3. SMS: "Thanks for meeting! Leave a review: …"
    4. Tag contact in Mautic.

  9. 09 · Chatwoot → CRM sync ⭐

    New inbox conversation → find or create in Twenty

    Trigger: Chatwoot conversation_created webhook

    1. Extract sender name, email, phone.
    2. Search Twenty by email.
    3. If found: log a note with the Chatwoot conversation ID.
    4. If not found: create a new person in Twenty.
