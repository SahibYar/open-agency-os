n8n recipes

How the disconnected pieces become one product

These are the first four agency paths. JSON exports live in n8n/workflows/ on GitHub. Import them after the core profile is up.

  1. 01 · 25 min

    Form → Twenty contact → Mautic segment

    Trigger: WordPress or native form POST

    1. Form hits n8n webhook.
    2. Normalize name, email, phone, source.
    3. Upsert person in Twenty GraphQL.
    4. Create or update Mautic contact and add to a segment.
    5. Open a Chatwoot conversation if the lead asked a question.

  2. 02 · 20 min

    Speed-to-lead SMS in 60 seconds

    Trigger: New Twenty person with source = ads

    1. Twenty webhook → n8n.
    2. Quiet hours check.
    3. Twilio SMS with first-name merge.
    4. Log the message on the contact.
    5. If no reply in 10 minutes, create a Chatwoot assignment.

  3. 03 · 15 min

    Cal.com booking → pipeline + reminder

    Trigger: BOOKING_CREATED

    1. Match attendee email to Twenty.
    2. Move opportunity to Booked.
    3. Mautic: enroll in appointment nurture.
    4. n8n wait until T-24h, send SMS reminder.

  4. 04 · 40 min

    Chatwoot sidebar shows CRM context

    Trigger: Conversation opened

    1. Lookup Twenty by email or phone.
    2. Post a private note: deals, last campaign, tags.
    3. If unknown, create a lead and tag source = inbox.
