Deploy

Self-host the agency OS

This site is the map. The runnable definition lives in the public repository: compose files, env templates, Caddyfile, and n8n exports.

  1. 01

    Provision a box

    16 GB RAM is the realistic floor for CRM + n8n + inbox. 8 GB is fine for core (Caddy + Postgres + Redis + n8n) while you learn.

  2. 02

    Clone the repo

    git clone https://github.com/SahibYar/open-agency-os.git && cd open-agency-os && cp .env.example .env

  3. 03

    Bring up core

    docker compose --profile core up -d — Caddy, Postgres, Redis, n8n. Open n8n on the glue hostname.

  4. 04

    Add one layer at a time

    crm, inbox, booking, marketing, pages are compose profiles. Do not enable all of them on a laptop.

  5. 05

    Import playbooks

    n8n → Import from n8n/workflows. Point webhooks at your public glue URL.
