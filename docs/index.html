The manifesto

GoHighLevel won because it bundled CRM, SMS, funnels, calendars, and agency sub-accounts into one login. The tax is lock-in: your contacts, automations, and client work live on someone else’s meter.

The open-source world already has each piece. Twenty is a serious CRM. Mautic is a serious campaign engine. Chatwoot is a serious inbox. Cal.com is a serious scheduler. n8n is a serious automation bus. They are disconnected. Agencies should not have to become platform engineers to use them together.

Aperture is the public attempt to integrate them — compose files, identity, playbooks, and a control plane — so any agency can self-host a HighLevel-class stack for the cost of a server.

What we will not fake

White-label SaaS mode

GHL sells sub-accounts. We start with Caddy hostnames + per-client n8n credentials. A true snapshot/SaaS control plane is a tracked issue.

Reputation management

No mature open-source Birdeye equivalent. Reviews stay a playbook (Google + n8n) until a dedicated module lands.

Unified login

Each product has its own auth today. Roadmap: Authelia or Pocket ID in front of the gateway.

You are the integrator

This is honest. The software is free. The work of keeping versions, backups, and deliverability healthy is yours — or your DevOps partner’s.
