Layer map

Eight products. One operating system.

We pick one default per layer so agencies are not staring at a catalog. Swaps are documented. The contract is the event bus — n8n webhooks — not a proprietary schema.

CRM & pipelines · Contacts, companies, deals, custom objects.

Twenty — Modern CRM core

Upstream. Fastest-growing open CRM. GraphQL, custom objects, a UI agencies will actually use. Replaces GHL pipelines, contacts, opportunities. License AGPL-3.0. Compose profile crm.

Marketing automation

Mautic — Campaign engine

Upstream. Closest open-source equivalent to HighLevel marketing automation. License GPL-3.0. Profile marketing. Needs MariaDB.

Conversations

Chatwoot — Omnichannel inbox

Upstream. Web widget, email, WhatsApp, Instagram, Facebook. License MIT. Profile inbox.

Calendars

Cal.com — Scheduling

Upstream. Self-hostable booking with team routing and webhooks into n8n. License AGPL-3.0. Profile booking.

Funnels & sites

WordPress

Upstream. Landing pages, forms, memberships. Forms post to n8n. License GPL. Profile pages.

Workflow glue

n8n — Automation bus

Upstream. Self-hostable, code nodes, executions not per-step. Fair-code Sustainable Use + Enterprise. Always on. Profile core.

SMS & voice

Twilio (or any SIP/SMS)

Upstream. Keep the pipe separate. Swap carriers without migrating the CRM. Commercial API. Keys in .env.

Edge

Caddy — HTTPS gateway

Upstream. Automatic TLS. One hostname per service. License Apache-2.0. Profile core.
